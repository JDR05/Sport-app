# Dokumentation

Produkt- und Architekturentscheidungen. Die dauerhaften Projektregeln stehen in
`../CLAUDE.md`, das Entscheidungsprotokoll in `../DECISIONS.md`.

| Dokument | Inhalt |
| --- | --- |
| `PRODUCT_SPEC.md` | Was das Produkt ist: Problem, Zielbild, Prinzipien, Zielsystem, Screens |
| `USER_FLOWS.md` | Wie der Nutzer sich durch das Produkt bewegt, inklusive Abbruchfälle |
| `ARCHITECTURE.md` | Sechs Schichten, Modulstruktur, Datenfluss, Grenze Deterministik/AI |
| `DATABASE.md` | Entitäten, Beziehungen, Statuswerte, Row Level Security |
| `AI_ARCHITECTURE.md` | Aufgaben des AI-Layers, strukturierte Outputs, Validierung, Fallback |
| `ADAPTIVE_ENGINE.md` | Die Lernschleife im Detail: Erkennung, Hypothese, Experiment, Regel |
| `MVP_SCOPE.md` | Was im MVP enthalten ist, was nicht, und wann er als fertig gilt |
| `ROADMAP.md` | Entwicklungsstufen V0–V3 und die Schrittfolge der Umsetzung |

Diese Dokumente sind aus zwei Quelldokumenten des Product Owners abgeleitet: dem Produktplan
(Vision und Anforderungen) und dem Playbook (Entwicklungsprozess).
